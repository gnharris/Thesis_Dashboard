Campus Heating Anomaly Dashboard

Independent monitoring window (Oct–Dec 2025)
What this dashboard shows

This dashboard summarises detected heating anomalies across campus buildings during deployment-style testing. Select a building to view its anomaly events and severity statistics.

  • Map markers: colour indicates mean severity (lighter = lower, darker = higher); size indicates event count.
  • Right panel KPIs: event count, total event hours, mean severity, peak severity for the selected building.
  • Event table: events ranked by impact (AE_sum). Use the search box to filter by type or ID.
  • Thr max: peak adaptive threshold during the event. Over thr (%): how far AE_max exceeded that threshold.
  • Downloads: export events for a building, filtered events, or building-level metrics.
